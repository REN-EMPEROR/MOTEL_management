GRANDSTAY HOTEL MANAGEMENT SYSTEM
================================

Technology:
- Python
- Flask
- SQLite 3
- HTML5
- CSS3

Features:
1. Hotel dashboard
2. Room management
3. Add rooms
4. Guest booking
5. Automatic night calculation
6. Room availability status
7. Booking list
8. Checkout
9. Automatic bill/invoice generation
10. Print / Save bill as PDF using browser print
11. Responsive colorful interface

HOW TO RUN:
1. Install Python 3.
2. Open Command Prompt/Terminal in this folder.
3. Run:
   pip install -r requirements.txt
4. Run:
   python app.py
5. Open:
   http://127.0.0.1:5000

The SQLite database (hotel.db) is automatically created on first run.
